# Traffic ML & Video Analytics Engine

High-performance real-time multi-camera traffic monitoring, vehicle tracking, speed estimation, ROI vehicle counting, and live web telemetry dashboard.

## Overview
- **YOLOv8 Detection**: Real-time vehicle detection with GPU acceleration.
- **ByteTrack Tracking**: Accurate multi-object tracking and trajectory analysis across cameras.
- **Road Movement & Speed Estimation**: Vector math and homography-based real-time speed calculation.
- **ROI Counting**: Precise directional entry/exit polygon vehicle counting.
- **FastAPI Backend**: Streaming endpoints, telemetry WebSockets, and job managers.
- **React Frontend**: Clean, responsive dashboard for real-time camera views and analytics metrics.
